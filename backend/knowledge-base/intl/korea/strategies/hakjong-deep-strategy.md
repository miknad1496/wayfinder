# 학종 (학생부종합전형) 깊이 있는 전략 — Wayfinder 심층 자료

학종은 한국 입시의 핵심 트랙. 외고/자사고/과고/영재고 학생은 거의 학종 위주, 일반고 상위권도 학종 노리는 경우 다수.

## 학종 평가 4축 (대학 입학사정관 발표 기준)

1. **학업역량 (Academic Competence)** — 단순 등급이 아니라 학업의 깊이.
2. **계열적합성 (Major Fit)** — 지원 학과/계열에 대한 학습 + 활동의 진정성.
3. **인성 (Character)** — 협력·리더십·책임감.
4. **발전가능성 (Growth Potential)** — 1학년부터 3학년까지의 변화·성장 곡선.

## 학생부 (학교생활기록부) 구성 요소 + 채우는 법

### 교과 성적
- 모든 주요 과목 (국어·영어·수학·과학·사회) 1등급. 평균 1.0~1.3등급이 SKY 학종 합격선.
- 과목별 성취도 (A-E) + 등급 (1-9).

### 세특 (세부능력 및 특기사항)
- 각 과목 담당 교사가 학생의 수업 활동을 서술적으로 기록. **양보다 질**. 깊이 있는 활동 1개 > 평범한 활동 10개.
- 좋은 세특 예: "○○○ 학생은 미적분 시간에 다항함수의 극한 개념을 학습한 후, 푸리에 급수의 수렴성에 대한 추가 탐구를 진행함. 학교 도서관에서 대학 미적분학 교재를 활용하여 ε-δ 정의를 직접 증명해보고, 발표 자료에서 학습 과정의 시행착오를 명확히 설명함."
- **나쁜 세특**: "수학에 관심이 많고 학습 태도가 우수함." (Generic.)

### 창체 (창의적 체험활동)
- **자율활동**: 학교 행사, 학급 활동, 학생회.
- **동아리활동**: 진로와 연결되는 학술/탐구 동아리. 의대 지원자 → 의생명탐구. 컴공 지원자 → 알고리즘·정보.
- **봉사활동**: 의무 시간 (대부분 60시간/3년) + 자율 시간. **순수 시간 채우기 X → sustained engagement**. 같은 기관에서 3년 지속 봉사가 강력.
- **진로활동**: 진로 탐색 + 직업 체험.

### 행특 (행동특성 및 종합의견)
- 담임교사가 학생의 종합 평가를 서술. 인성 + 학업 태도 + 성장 모습.

### 자기소개서 (2024년 폐지)
- 2024학년도부터 학종 자소서 미요구. 평가는 학생부만으로.

## 1학년 1학기부터 학종 채우는 5단계 전략

### Step 1: 진로 결정 (1학년 1학기 시작 전)

- 모호한 "이공계열" 보다 구체적인 "의예과 / 컴공 / 화학공학 / 생명공학" 같은 지정.
- 진로가 너무 일찍 고정되면 부담 — 1학년 1학기는 탐색 단계 OK. 2학년 시작 전에 우선순위 1-2개로 좁히기.

### Step 2: 교과 1.0~1.5등급 유지 (모든 학기)

- 한 학기라도 2등급 떨어지면 SKY 학종 어려워짐.
- 어려운 과목 중심 선행학습 + 학원 활용. 사교육 효과적 활용.

### Step 3: 세특 채우기 — 매 학기

- 매 과목 수업에서 단순 발표 X → **추가 탐구 1개 보고서 + 발표 + 교사에게 학습 과정 공유**.
- 교사가 세특 작성할 때 구체적인 학습 활동을 서술할 수 있도록 학생이 인풋 제공.
- 좋은 학교는 자율탐구 시간 제공. 외고/자사고는 매 학기 자율탐구 보고서 작성하는 환경.

### Step 4: 창체 시리즈 만들기

- 동아리 1개 (3년 누적): 진로와 연결. 의대 지원자 → 의생명연구반 1-3학년.
- 봉사 1-2개 (3년 누적): 진로와 연결되는 곳. 의대 → 의료봉사·노인 요양 시설. 컴공 → 코딩 멘토링.
- 진로 활동: 직업 체험 + 진로 책 읽기 + 진로 멘토와 인터뷰.

### Step 5: 자율탐구 (소논문) 시리즈

- 가장 강력한 차별화. 학교 자율탐구 시간을 활용한 심화 연구.
- 1학년: 입문적 자율탐구. 2학년: 본격적인 분석 + 정량 연구. 3학년: 정리 + 발전.
- 한 시리즈로 누적되면 학종 평가에서 매우 강한 시그널.

## 학교별 학종 친화도 — 외고/자사고 vs 일반고

학종 평가에서 큰 변수는 학교 자체의 학종 환경:
- **외고/자사고/과고/영재고**: 교사 한 명당 학생 수가 적음 → 깊이 있는 세특 작성 가능. 자율탐구 시간 제공. 학종 진학 실적이 학교 자체의 자본.
- **일반고**: 학생 수 많음 → 세특 평이한 경우 多. 자율탐구 시간 부족. 학종 진학에 학생 본인의 노력이 더 필요.

→ 일반고 학생이 학종 노리면:
1. 세특 인풋을 적극적으로 교사에게 제공.
2. 학교 외부 활동 (봉사·동아리·연구) 강화.
3. 정시 + 학종 동시 준비 (학종 어려우면 정시 fallback).

## 자기소개서 폐지 후 (2024+) 학생부의 더 큰 역할

- 자소서가 사라져 학생부 본문이 평가의 거의 전부.
- 학생부 작성 깊이를 위해 교사와 학생의 협업이 더 중요.
- "학생이 무엇을 했는가" + "교사가 무엇을 봤는가" 두 측면 모두 강해야.

## 의대 학종 — 추가 깊이

위 전략에 더해:
- 생물·화학·물리 세특에서 의학 연결 깊이.
- 의생명 동아리 (학교 자체 또는 외부 의예 캠프).
- 의료 봉사 sustained.
- 의대 면접 대비: 인성 + 윤리적 판단 (의료 윤리 사례).

## 일반고 학생이 학종으로 SKY 가는 사례

가능하지만 어려움. 표준 프로필:
- 1학년 1.0~1.2등급 평균 유지.
- 매 학기 자율탐구 시리즈.
- 외부 활동 (대학 연구실 인턴십, 봉사 sustained).
- 진로 일관성.
- 강한 면접 준비.

지원 학교 전략:
- SNU·연대·고대 학종 도전.
- 보험: 서성한 학종 + 정시 동시.

## 한국 부모님 흔한 오해

오해: "학종은 노력하면 되는 거 아닌가요?"
→ 학종은 노력 + 환경 + 일관성의 종합. 학교 환경이 큰 변수. 일반고 학생은 외고/자사고 학생 대비 평균 1.5배 더 힘듦.

오해: "1, 2학년에는 좀 놀고 3학년에 학종 채울 수 있죠?"
→ 절대 X. 학종은 1, 2학년 학생부가 핵심. 3학년 1학기까지 누적된 학생부로 평가.

오해: "사교육 학원이 학종 도와주나요?"
→ 학원은 교과 등급 (정시 + 학종 최저)에 도움. 학종 평가 항목 (세특·창체) 자체는 학교 안에서만 채울 수 있음. 외부 컨설팅이 학생부 자체를 작성하지는 못함.
