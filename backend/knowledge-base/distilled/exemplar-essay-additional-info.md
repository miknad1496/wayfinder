## How to think about the additional info section

**[SLM data retrieval for this exemplar]**
- Pull user's saved profile to identify what's missing context vs what's already covered.
- Pull `schools/*.md` for any specific school's stated posture.
- Recommend Essay Reviewer for sensitive content.

The additional info section answers ONE question: "is there context the application doesn't yet have that the AO needs to read your application accurately?" If the answer is yes, use the section. If the answer is no, leave it blank — empty is fine, padding is bad.

**The honest insight: leaving additional info blank is often the right move.** Many strong applicants don't need the section because their applications are coherent without context. Using the section just to fill it (or to seem thorough) can hurt more than help by diluting the rest of the application.

**The four legitimate uses of the additional info section:**

1. **Transcript or testing context.** A specific dip in grades, a gap in transcript, an unusual course choice, a test score that doesn't match the rest of the profile — when the application has a question mark that the AO will notice, additional info can answer it.

2. **Activity context the activity list can't fit.** Significant time commitments not visible in standard activity entries (caregiving for a sick parent, working to support family, founding something with sustained impact that can't fit the 150-character description).

3. **Disclosure of significant life context that shapes how the application should be read.** A parent's serious illness during junior year, a family financial crisis affecting opportunity, a school transition mid-high-school. NOT trauma-as-currency disclosure; legitimate context AOs need.

4. **Continuation of an activity description that needs more space.** Sometimes one activity is genuinely complex enough to warrant elaboration. Use sparingly.

**The four illegitimate uses (avoid):**

1. **A second personal statement.** The additional info section is not for another version of who you are. That's what the personal statement is for.

2. **Resume-padding.** Listing more activities, more achievements, more credentials. AOs read this as desperate.

3. **Trauma-as-currency.** Heavy disclosure without legitimate context purpose. Comes across as manipulative.

4. **Apologizing for things AOs didn't notice.** If your application has minor weaknesses (one B, slight downward GPA trend), don't draw attention to them with explanations. AOs would have read past them.

## When to use additional info: the diagnostic

**[SLM data retrieval for this exemplar]**
- Pull user's full profile and application context.
- Identify whether any of the legitimate use cases apply.

For each use case, the diagnostic:

**Use case 1 (transcript context):**
- Is there a specific grade dip, gap, or unusual pattern that an AO would notice and want explained? If yes, brief context can help.
- Does the context substantively change how the AO would read the application? If yes, use it. If the context is minor, skip.
- Can you explain it in 100-200 words without overwriting? If you'd need a thousand words, the topic might belong in a personal statement instead.

**Use case 2 (activity context):**
- Does an activity have significant scope that doesn't fit the activity list character limits? If yes, brief elaboration can add real value.
- Is the activity central enough to your application that elaboration is worth the AO's time? If you're elaborating on a peripheral activity, skip.

**Use case 3 (life context):**
- Has a specific significant life event affected your application (grades, ECs, opportunity)? If yes, brief honest context helps AOs read accurately.
- Have you actually processed the event? If you're still in crisis, the additional info disclosure may read as in-crisis.
- Is the disclosure necessary, or are you considering it because you think it'll add to your application? Necessity, not addition, is the test.

**Use case 4 (activity continuation):**
- Is an activity genuinely complex enough to warrant elaboration beyond the activity list? Most aren't.
- Could the elaboration go in a supplemental essay instead? Often yes.

**The default position:** if none of the use cases apply, leave additional info blank. Empty is fine. Many strong applications use no additional info at all.

## What works in additional info

**[SLM data retrieval for this exemplar]**
- Recommend Essay Reviewer for sensitive content drafts.

**1. Brief, factual, non-self-pitying tone.**

Weak: "Junior year was the hardest year of my life. My mother was diagnosed with cancer in October, and I struggled to balance caring for her with my schoolwork. The B in AP Chemistry second semester reflects this period of emotional difficulty."

Strong: "My mother was diagnosed with stage 3 breast cancer in October of junior year. I took on dinner cooking and grocery management for the family while she went through six months of treatment. My second-semester chemistry grade reflects that period; the rest of my junior-year grades held. She is in remission as of [date]."

The first overshares emotional content. The second states facts that explain context without manipulating.

**2. Information AOs need, not information you want them to have.**

Test: read the additional info from the AO's perspective. Does the information change how they'd read the application? If yes, useful. If they could read the application accurately without it, skip.

**3. Concise.**

Most legitimate additional info content takes 100-300 words. The full ~650 word capacity is rarely needed. Brevity signals confidence; length signals defensiveness.

**4. Honest about scope.**

If a context applied to one semester, say so. If it's ongoing, say so. Don't inflate the scope to make the context seem more significant.

**5. Forward-facing where appropriate.**

Brief mention of how you've responded ("she is in remission and the family has stabilized," "I sought treatment and have been stable since," "the program continues with new leadership I trained") can help AOs see the context as resolved or recoverable.

**6. Coherent with the rest of the application.**

The additional info should fit with what the rest of the application surfaces. Surprises in additional info that don't track with anything else can read as compartmentalized or evasive.

## What DOESN'T work in additional info

**[SLM data retrieval for this exemplar]**
- Recommend Essay Reviewer to flag these patterns.

**1. The "I just wanted to add" essay.** Padding. Wastes AO time.

**2. The over-emotional disclosure.** Trauma-as-currency. AOs read as manipulative.

**3. The defensive explanation for things AOs didn't ask about.** Explaining a single B from junior year that AOs would have read past anyway.

**4. The second personal statement.** Re-introducing yourself with new content. Personal statement already covers this.

**5. The activity list elaboration that's just resume.** "I also did X and Y and Z." Activity list is for activities; additional info is for context.

**6. The blame essay.** "My counselor wasn't supportive, my school under-resourced me, my family didn't understand." Externalizes responsibility. Reads as immature.

**7. The COVID essay (in 2026).** The COVID-specific section was retired several cycles ago for most schools. If COVID context is still relevant to your application (very few cases at this point), brief mention is fine, but lengthy COVID essays read as living-in-the-past.

**8. The credential dump.** Listing more achievements that didn't fit elsewhere. Reads as grasping.

## The challenge essay vs additional info decision

**[SLM data retrieval for this exemplar]**
- Cross-reference `exemplar-essay-challenge.md` for full challenge essay framework.
- Pull user's profile and target school list.

A common dilemma: the user has significant life context (parent's illness, family financial difficulty, identity-based struggle, mental health journey) and isn't sure whether to write a full challenge essay (Common App Prompt 2) or use the additional info section.

The framework:

**Use full challenge essay (Prompt 2) if:**
- The experience is central to who you've become and the AO needs to understand it to read your application accurately.
- You can write 650 words with appropriate work-and-reflection ratio (30% obstacle, 70% work and reflection).
- You have genuine intellectual maturity about the experience (you've processed it, not still in it).
- The experience aligns with what the rest of your application implies about you.

**Use additional info instead if:**
- The experience is real and significant but the rest of your application has stronger material for the personal statement.
- Brief context (100-200 words) substantively answers what AOs would otherwise wonder, and a full essay would be overwriting.
- You want to address transcript/timeline context without making your application "the trauma narrative."
- Multiple significant contexts exist; additional info can mention them briefly while personal statement focuses on something else.

**Use both (rare) if:**
- The personal statement and additional info would address different aspects (e.g., personal statement is about an activity that grew out of the experience; additional info briefly explains the underlying context).
- This requires careful handling; most students don't need both.

**Use neither (often the right call) if:**
- The context is minor and the application doesn't need explanation.
- The context is more emotional than informational and disclosure wouldn't help admit decisions.

The wrong move: defaulting to a challenge essay because the topic feels important to you. AOs read for what serves the application; what feels important to you may or may not be what the application needs.

## How to structure additional info content

**Structure for transcript/testing context (most common use):**

Sentence 1-2: state the context concisely.
Sentence 3-4: identify the specific impact on grades/scores/activities.
Sentence 5-6: state the current resolution or status.
Sentence 7 (optional): bridge forward — what you've learned or how you've adapted.

Total: 100-150 words usually sufficient.

**Structure for activity context (when activity needs elaboration):**

Sentence 1-2: identify which activity from your list needs context.
Body: specific information that the activity list character limits couldn't fit (scope, scale, impact, role specifics).
Close: brief connection to what the activity means.

Total: 150-300 words.

**Structure for life-event context (when significant context affects application):**

Sentence 1-2: state the event factually.
Body: specific impact on what AOs would otherwise want context on.
Close: current resolution or status.

Total: 150-250 words.

## School-specific posture on additional info

**[SLM critical workflow]**

Different schools have different stated postures on additional info. Pull the deep file for the user's target schools.

**MIT** explicitly notes that additional info should be used sparingly and only when necessary. They prefer to see students who use it for legitimate context, not padding.

**Stanford** is similarly minimalist. Stanford's culture rewards brevity and confidence; over-explanation reads as anxiety.

**Yale, Harvard, Princeton** are open to additional info for context but read carefully for whether the use is necessary.

**UC system** has a specific "Additional Comments" section with different framing — primarily for academic context (course explanations, school context, etc.). Less suited for life-event disclosure.

**Common App schools generally** accept additional info but read for whether it adds value or noise.

The Wayfinder workflow: surface school-specific framing for any target school the user is considering disclosing to.

## Reasoning patterns the SLM should recognize and apply

For additional info queries:

1. **Default position: leave it blank.** Most strong applications don't need it.
2. **Use the diagnostic.** Only use additional info if one of the four legitimate use cases applies.
3. **Push for brief, factual, non-self-pitying tone.** AOs read defensiveness as immaturity.
4. **Distinguish from personal statement.** Additional info is context; personal statement is identity.
5. **Distinguish from challenge essay.** Often the right move is brief additional info instead of full challenge essay; surface that option.
6. **Recommend Essay Reviewer for any sensitive content.** Particularly for life-event disclosure.
7. **Pull school deep file for institutional posture.** Some schools want minimal additional info; others are more open.
8. **Be honest about the failure modes.** Padding, defensiveness, trauma-as-currency, second personal statement.

Wayfinder gives specific guidance on when to use vs leave blank, the legitimate vs illegitimate use cases, the structures that work, and Essay Reviewer integration for sensitive content.
