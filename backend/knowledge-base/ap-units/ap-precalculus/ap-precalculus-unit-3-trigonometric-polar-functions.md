## Unit at a Glance

- **Exam weight:** ~30–35% of the AP Precalculus exam
- **Sub-topics covered:** unit circle; sine, cosine, tangent (and reciprocals); transformations of trig functions (amplitude, period, phase shift); inverse trig; identities; polar coordinates; polar curves.
- **Where this unit appears on the exam:** Unit circle values. Solving trig equations. Identities. Polar curves and graphs.

## Big Ideas

1. **Unit circle:** sin and cos as coordinates of point on unit circle.
2. **Trig functions are periodic:** sin/cos period 2π; tan period π.
3. **Transformations:** amplitude (A), period (2π/B), phase shift (C/B).
4. **Identities** simplify and solve.
5. **Polar coordinates:** (r, θ); r = f(θ) defines polar curves.

## Tier-Tagged Content

### Foundational [3] — needed for any score

- **Unit circle (radius 1, center origin):**
  - **Point at angle θ:** (cos θ, sin θ).
  - **Quadrant signs:** Q1 (+,+), Q2 (−,+), Q3 (−,−), Q4 (+,−).
- **Common values:**
  - **0, π/6 (30°), π/4 (45°), π/3 (60°), π/2 (90°).**
  - **(cos, sin):** (1, 0), (√3/2, ½), (√2/2, √2/2), (½, √3/2), (0, 1).
- **Tangent:** tan θ = sin θ / cos θ.
- **Reciprocals:**
  - **csc θ = 1/sin θ.**
  - **sec θ = 1/cos θ.**
  - **cot θ = 1/tan θ.**
- **Pythagorean identity:** sin²θ + cos²θ = 1.
- **Other identities:**
  - **tan²θ + 1 = sec²θ.**
  - **1 + cot²θ = csc²θ.**
- **Sum/difference (selectively):**
  - **sin(A ± B) = sin A cos B ± cos A sin B.**
  - **cos(A ± B) = cos A cos B ∓ sin A sin B.**
- **Double-angle:**
  - **sin(2θ) = 2 sin θ cos θ.**
  - **cos(2θ) = cos²θ − sin²θ = 1 − 2sin²θ = 2cos²θ − 1.**
- **General sinusoidal function:**
  - **f(x) = A sin(B(x − C)) + D.**
  - **A:** amplitude.
  - **2π/B:** period.
  - **C:** phase shift (right if C > 0).
  - **D:** vertical shift.
- **Inverse trig:**
  - **arcsin (or sin⁻¹):** range [−π/2, π/2].
  - **arccos:** range [0, π].
  - **arctan:** range (−π/2, π/2).
- **Polar coordinates:** (r, θ).
  - **x = r cos θ, y = r sin θ.**
  - **r = √(x² + y²), θ = arctan(y/x).**
- **Polar curves:**
  - **r = a (circle radius a).**
  - **r = a + b cos θ (limaçon).**
  - **r = a sin(nθ) (rose with n petals if n odd, 2n if even).**

### Adds for [4]

- **Solving trig equations:**
  - Isolate trig.
  - Use unit circle for principal values.
  - Add 2π·k or π·k for general solution (depending on function).
- **Identity proofs:** transform one side to match other.
- **Polar to Cartesian conversion practice:**
  - **r = 4 cos θ:** multiply by r → r² = 4r cos θ → x² + y² = 4x → (x−2)² + y² = 4 (circle).

### Adds for [5]

- **Why sine and cosine "everywhere":** model periodic phenomena (sound, light, oscillation, biological cycles).
- **Why polar useful:** circular and spiral patterns natural.

## Worked Examples

### Example 1 [3] — Unit circle

cos(2π/3)?
- **2π/3 = 120°, in Q2.**
- **Reference angle:** π/3 → cos = ½.
- **Q2 cos negative:** −½.

### Example 2 [3] — Solve trig equation

sin x = ½ on [0, 2π).
- **Principal:** x = π/6.
- **Other:** x = π − π/6 = 5π/6 (Q2 also positive sin).
- **Solutions:** π/6, 5π/6.

### Example 3 [4] — Sinusoid

f(x) = 3 sin(2(x − π/4)) + 1. Identify properties.
- **Amplitude:** 3.
- **Period:** 2π/2 = π.
- **Phase shift:** right π/4.
- **Vertical shift:** up 1.
- **Range:** [1−3, 1+3] = [−2, 4].

### Example 4 [4] — Identity

Verify: sin(2x) = 2 sin x cos x. (Already an identity; use sum formula.)
- **sin(2x) = sin(x + x) = sin x cos x + cos x sin x = 2 sin x cos x.** ✓

### Example 5 [5] — Polar curve

r = 2 + 2 cos θ. Identify and sketch.
- **Limaçon (cardioid since a = b).**
- **At θ = 0:** r = 4 (max).
- **At θ = π:** r = 0 (passes through origin).
- **Heart-shaped curve.**

## Top Traps & Common Errors

1. **Sign errors** by quadrant — memorize ASTC ("All Students Take Calculus") for which trig is positive in each quadrant.
2. **Phase shift direction:** sin(B(x − C)) shifts RIGHT by C.
3. **Inverse trig range** restrictions.
4. **Period of tan is π** (not 2π).
5. **Polar curve symmetries** — recognize roses, limaçons, cardioids.

## Rubric-Aware Tactics

**For trig equation:** find principal solutions; add periods.
**For sinusoid:** identify A, B, C, D from form.
**For polar:** convert to Cartesian if helpful; use known curve types.

## "Phrases That Score" — verbatim language for FRQs

1. "On the unit circle, the point at angle θ has coordinates (cos θ, sin θ). Tangent: tan θ = sin θ / cos θ."
2. "Pythagorean identity: sin²θ + cos²θ = 1. Derived: tan²θ + 1 = sec²θ; 1 + cot²θ = csc²θ."
3. "General sinusoidal function f(x) = A sin(B(x − C)) + D has amplitude A, period 2π/|B|, phase shift C (right if positive), and vertical shift D."
4. "Inverse trig functions have restricted ranges to ensure they're functions: arcsin has range [−π/2, π/2]; arccos has range [0, π]; arctan has range (−π/2, π/2)."
5. "Polar coordinates (r, θ) relate to Cartesian by x = r cos θ, y = r sin θ. Curves like r = a + b cos θ form limaçons (cardioid when a = b); r = a sin(nθ) forms n-petal roses (or 2n if n is even)."
