## Big Ideas

1. **Perception is constructive.** Brain builds reality from sensory input + expectations + experience.
2. **Memory has multiple stores:** sensory (brief), short-term/working (limited), long-term (vast).
3. **Memory is reconstructive, not exact.** Memories can be distorted, especially under suggestion.
4. **Intelligence is multifaceted.** Single IQ score captures only some aspects.
5. **Heuristics and biases shape decision-making.** Mental shortcuts useful but produce systematic errors.

## Tier-Tagged Content

### Foundational [3] — needed for any score

- **Perception:** how we INTERPRET sensory information.
  - **Top-down:** start with experience/expectations.
  - **Bottom-up:** start with raw sensory data.
- **Gestalt principles:** brain organizes perception into wholes.
  - **Proximity:** elements close together perceived as group.
  - **Similarity:** similar elements grouped.
  - **Closure:** brain fills in gaps.
  - **Continuity:** elements following same path grouped.
  - **Figure-ground:** distinguish object from background.
- **Depth perception:**
  - **Binocular cues:** retinal disparity (different images in each eye), convergence (eyes turn inward).
  - **Monocular cues:** linear perspective, relative size, interposition (closer blocks farther), texture gradient.
- **Perceptual constancy:** objects appear same shape/size despite changing viewing angle.
- **Memory model (Atkinson-Shiffrin / multi-store model):**
  - **Sensory memory:** brief (~1 second). Iconic (visual), echoic (auditory).
  - **Short-term/working memory:** limited capacity (~7 ± 2 items, Miller); ~20-30 seconds without rehearsal.
  - **Long-term memory:** vast capacity, durable.
- **Working memory model (Baddeley):**
  - **Central executive:** controls attention.
  - **Phonological loop:** verbal/auditory information.
  - **Visuospatial sketchpad:** visual/spatial information.
  - **Episodic buffer:** integrates information.
- **Long-term memory types:**
  - **Explicit (declarative):** conscious recall.
    - **Episodic:** personal events.
    - **Semantic:** facts, knowledge.
  - **Implicit (procedural):** unconscious; how to do things (riding bike).
- **Encoding strategies:**
  - **Rote rehearsal:** repetition.
  - **Elaborative rehearsal:** linking to existing knowledge. More effective.
  - **Semantic encoding:** meaning-based.
  - **Acoustic:** sound-based.
  - **Visual:** image-based.
  - **Mnemonics:** memory aids (acronyms, method of loci, chunking).
- **Forgetting:**
  - **Decay:** memory fades over time.
  - **Interference:** other information disrupts memory.
    - **Proactive:** old interferes with new.
    - **Retroactive:** new interferes with old.
  - **Retrieval failure:** memory exists but can't be accessed.
- **Memory distortions:**
  - **Misinformation effect (Loftus):** post-event information distorts memory.
  - **False memories:** memories of events that didn't happen.
- **Intelligence:**
  - **General intelligence (g):** Spearman's single factor.
  - **Multiple intelligences (Gardner):** linguistic, logical-mathematical, spatial, musical, bodily-kinesthetic, interpersonal, intrapersonal, naturalist.
  - **Fluid intelligence:** problem-solving in novel situations.
  - **Crystallized intelligence:** accumulated knowledge.
- **IQ tests:**
  - **Mean = 100, SD = 15** (most modern tests).
  - **Stanford-Binet, WAIS** (Wechsler Adult Intelligence Scale).
  - **Reliability:** consistent results over time.
  - **Validity:** measures what it claims.
- **Heuristics and biases (Kahneman, Tversky):**
  - **Availability heuristic:** judging based on what comes to mind easily.
  - **Representativeness heuristic:** judging based on stereotypes.
  - **Anchoring:** depending too heavily on first piece of information.
  - **Confirmation bias:** seeking information that confirms existing beliefs.

### Adds for [4]

- **Why memory is reconstructive.**
  - Each retrieval re-encodes the memory.
  - Suggestible to misinformation and leading questions.
  - Different retrievals may produce different details.
- **Loftus's misinformation effect research.**
  - Studies showed witnesses' memories shaped by post-event information.
  - Implications for eyewitness testimony reliability.
- **Schemas and memory:**
  - Mental frameworks that help organize information.
  - Influence what is remembered and how.
- **Intelligence controversies:**
  - **Cultural bias** in IQ tests.
  - **Nature vs nurture** debates about intelligence.
  - **Flynn effect:** rising IQ scores over time across populations.
- **Prefrontal cortex** plays key role in working memory and decision-making.
- **Confirmation bias** affects how people interpret evidence.

### Adds for [5]

- **Why working memory matters.**
  - Limits how much we can hold/process at once.
  - Implications for education, multitasking, attention.
- **Gardner's multiple intelligences vs Spearman's g:** debated. Most psychologists accept some general intelligence factor while acknowledging multiple specific abilities.
- **Implications of memory distortion** for legal system. Eyewitness testimony has been overturned by DNA evidence in many cases.

## Worked Examples

### Example 1 [3] — Memory model identification

A student studies vocabulary by linking new words to personal experiences. What encoding strategy is this?
- **Elaborative rehearsal** (semantic, meaningful encoding).

### Example 2 [3] — Memory types

For each, identify the type of long-term memory:
(a) Knowing how to ride a bike.
(b) Remembering what happened on your 16th birthday.
(c) Knowing the capital of France is Paris.

- (a) **Procedural** (implicit).
- (b) **Episodic** (explicit, personal events).
- (c) **Semantic** (explicit, facts/knowledge).

### Example 3 [4] — Heuristics

A person hears about plane crashes on the news and now fears flying more than driving. What heuristic is at work?
- **Availability heuristic** — vivid news stories make plane crashes seem more common than they are.
- (Statistically, driving is FAR more dangerous than flying.)

### Example 4 [4] — Misinformation effect

A witness to a car accident is asked: "How fast was the car going when it SMASHED into the other car?" Later asked about the speed.
- The word "smashed" leads them to remember higher speed.
- This illustrates Loftus's misinformation effect.

### Example 5 [4][5] — Working memory limits

Why do people often forget the second half of a long phone number?
- Working memory has limited capacity (~7 ± 2 items, Miller).
- A long phone number exceeds capacity if not rehearsed or chunked.
- "Chunking" can help (grouping numbers, e.g., 555-867-5309).

## Top Traps & Common Errors

1. **Confusing sensation and perception.** Sensation = receiving stimuli. Perception = interpreting.
2. **Wrong memory store characteristics.** Sensory (brief). Short-term (limited). Long-term (vast).
3. **Mixing implicit and explicit.** Explicit (conscious). Implicit (unconscious, like skills).
4. **Treating memory as accurate recording.** Memory is reconstructive, not exact.
5. **Confusing types of intelligence.** General (g, Spearman). Multiple (Gardner). Fluid vs crystallized.
6. **Wrong heuristic descriptions.** Availability (what comes to mind). Representativeness (stereotypes). Anchoring (first information).
7. **Confusing types of interference.** Proactive (old → new). Retroactive (new → old).

## Rubric-Aware Tactics

**For memory questions:**
- Identify type of memory.
- Explain encoding/storage/retrieval process.

**For perception questions:**
- Distinguish bottom-up from top-down.
- Apply Gestalt principles.

**For intelligence questions:**
- Distinguish theories (general vs multiple).
- Address fluid vs crystallized.

**For decision-making questions:**
- Identify heuristic or bias.
- Predict effect.

5. "Intelligence is multifaceted. Spearman proposed general intelligence (g); Gardner proposed multiple intelligences (linguistic, logical, spatial, etc.); fluid vs crystallized distinguishes problem-solving from accumulated knowledge."
